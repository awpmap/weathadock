## WeathaDock 1.1.1

**A cleaner installer.** The setup wizard has new artwork, the WeathaDock icon throughout, and shorter, clearer wording.

If you already have 1.1.0, this update installs from inside the app: open Settings and choose Check for updates.

**Upgrading from 1.0.x:** uninstall the old version first (Settings, Apps, Installed apps), then run this installer once. Your locations carry over.
