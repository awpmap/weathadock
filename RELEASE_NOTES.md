## WeathaDock 1.1.2

**One-click installer.** Run the installer and that's it: one small WeathaDock window with a progress bar, no wizard pages and no questions, and the app opens as soon as it finishes. Installing over an existing copy updates it in place and keeps your settings.

If you already have 1.1.0 or later, this update installs from inside the app: open Settings and choose Check for updates.

**Upgrading from 1.0.x:** uninstall the old version first (Settings, Apps, Installed apps), then run this installer once. Your locations carry over.
